# Aseprite Chinese Localization

## Aseprite 简体中文汉化包

## 使用方法：
0. 下载汉化包
1. 打开Aseprite
2. 选项卡选择`Edit`->`Preferences`->`Extensions`->`Add Extension`
3. 选择汉化包
4. 加载扩展
5. 选项卡选择`Edit`->`Preferences`->`General`->`Language`->`sChinese`->`Apply`
6. 重启Aseprite
